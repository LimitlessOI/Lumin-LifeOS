# Stretch goal: +125% in a month

**Framing (Adam):** We don’t call it fantasy or impossible. The two-minute mile was “impossible” until it wasn’t. We pursue hard goals **without being reckless**.

**Goal:** **+125% in one calendar month** on the active LIP book (e.g. $10k → ~$22.5k).  
**Status:** **Not solved yet.** Blind tests have not printed this. That is a gap, not a stop.

---

## What “not reckless” means

| Do | Don’t |
|----|-------|
| Paper / tiny live caps first | Bet the house on unproven size |
| Kill switch + daily loss limit | Martingale / revenge size |
| Prove each leap on unused data | Curve-fit one lucky week |
| Many small accounts testing variants | One all-in hero trade |
| Label KNOW / THINK / GUESS | Sell the dream as current fact |

---

## Gap (honest)

| What we measured | vs +125%/month |
|------------------|----------------|
| P&D first-drop shorts | ~**+1% to +7%** per *event cluster* (days/weeks), small size |
| Breakout sleeve | ~**+5% to +30%** per *half-year* in bulls (often &lt; BTC) |
| BTC hold | Big in bulls; **−45%** in a bad half |
| Old optimistic sim | **+125% in 6 months** (early entry assumptions) — **not** +125%/month, and not matched in blind late-public tests |

**Math of the goal (THINK):**  
To turn $10k → ~$22.5k in 30 days with **small** sleeves (~8% per trade), you need either **many** high-edge trades or **larger** size on proven edge. Example: ~15 full-book trades at ~**+5.6% net each**, or ~60 trades at ~**+17% net** on 8% size — far above our current measured per-trade edge on public data.

So the goal is **extreme relative to today’s proved edge** — and still the **target we aim the research at**.

---

## Path toward it (not solved yet → next tries)

1. **Keep the proved base** — BTC core + P&D first-drop short + breakout+trail (don’t burn the book learning).  
2. **Amplify only what prints** — raise size on a sleeve only after N green unused segments + live tiny-cap proof.  
3. **Hunt early information** — up-path money needs being early; public shout is late. Legal/public early signals only (listings calendars, on-chain, filings — not organizing pumps).  
4. **More events / more books** — fleet of small accounts so one month can contain enough independent trials.  
5. **Leverage only behind caps** — if used, hard daily stop; never “one more size-up” after a loss.  
6. **Monthly scoreboard vs goal** — every month: actual % vs 125%. Gap = fuel for the next experiment, not shame.
