# Limitless Protocol — Lessons v3 (short-only)

Baked into `scripts/lip/blind/reader-lessons-v3.mjs`. Run: `npm run lip:blind:v3`.

## Hard answers

| Question | Answer |
|----------|--------|
| Buy on the way up if we’re too late? | **No.** Public shout with price already up = late. No long. |
| Are we just shorting? | **Yes.** Arm at shout → short first down 1m bar. Zero longs. |

## Lessons

1. Costs on every trade (~1.85% obscure RT)
2. Peak often minutes after shout — time-stop ~12m
3. Enter early or miss the *long* edge — at public shout we are usually too late to buy
4. Late long kills edge (−7% to −17% on blind segments)
5. First-drop short beat yell-bar short (E yell-bar was red; first-drop green)
6. Wider stop if already ran hard (+15% in 30m)
7. Abort if still mooning (+12% after shout before a drop)
8. One shot per event
9. Identify public pattern only — never organize
