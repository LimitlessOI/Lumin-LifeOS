# Collectibles — Monetization Architecture

**Status:** Resolved (founder merge 2026-08-12). Binding for manufacturing.  
**Labels:** `[FOUNDER]` · `[DERIVED]`

---

## 1. Constitutional rules

### 1.1 Recommendation integrity `[FOUNDER]`

> **Teloa's revenue may participate in value creation, but may never secretly redefine what Teloa tells the user is best for them.**

Monetization is subordinate to recommendation-integrity architecture (sponsored ≠ best; expected-net honesty; no secret listing).

### 1.2 Secret listing prohibition `[FOUNDER]`

Teloa does **not** earn by secretly listing user items. Liquidity states and explicit permission architecture govern visibility. Dark-pattern auto-list for revenue is forbidden.

### 1.3 Fee-display law (constitutional product behavior) `[FOUNDER]` / `[DERIVED]`

This is not mere UI guidance. It is required product behavior:

**V3+:** Any sell/trade recommendation must show **expected user net** after known/estimated:

- platform / take-rate fees  
- venue fees  
- payment fees  
- shipping  
- insurance (when material)  
- other material transaction costs  

Saying “this venue pays $110” when the user would receive ~$91 is a blueprint violation.

**V1:** There is not enough transaction context to manufacture expected net. V1 shows honest **market value range + confidence + freshness/provenance** only — never a fake “you’ll get $X” net.

**V2:** Offers may show offered amount; full expected-net settlement math arrives with Protected Exchange (V3) when venue/fees/shipping/insurance are known.

### 1.4 Cross-cutting principles

- V1 Vault must remain independently valuable without commerce pressure.
- No advertising-driven Vault home; no speculative price-movement optimization.
- Sponsored placement categorically separate from **Best Recommendation** (V5+).
- Partner revenue attributable per capability.
- Sell Agent / optimizer objective = user’s selected outcome, not maximizing Teloa’s fee (V4+).

## 2. Versioned revenue surfaces

### V1 — Trusted Vault

Optional subscription/freemium around scale or advanced digitization. Core Vault independently valuable. Alpha may be free. No advertising-driven Vault home; no commerce pressure; no take-rate on silent listings (none exist).

### V2 — Latent Liquidity

**Quiet Matching is a network primitive.** Basic quiet matching **may remain free**. Do **not** lock “Premium Quiet Matching” as the assumed V2 monetization model.

Potential later monetization: premium intelligence, advanced persistent acquisition agents, or other *enhanced* matching services — commercial configuration left flexible (`[FOUNDER-RESERVED]` packaging, not capability existence).

**Hard V2 economics law:** Basic quiet liquidity must never be intentionally degraded to manufacture subscription pressure. Never sell spam, preferential buyer harassment, hidden threshold access, or artificial reach suppression.

### V3 — Protected Exchange

Transparent transaction/platform fee or take-rate via payment adapter. All recommendations show **expected user net** per fee-display law (§1.3).

### V4 — Intelligent Commerce

Sell Agent may use success-fee, subscription, or hybrid economics. Objective remains maximizing the user’s selected outcome (cash target, speed, max-net, constraints) — **not** maximizing Teloa’s fee. Expected net includes agent/platform fees.

### V5 — Partner Network

Partner SaaS (inventory/storefront tools); commerce attribution; clearly labeled sponsored placement. Sponsored placement is categorically separate from Best Recommendation.

### V6 — Living Vault / Reveal

Scan upgrades; Reveal services; host revenue; custody/storage partner revenue share; fulfillment/handling; rights-permitted media economics. Custody/insurance marketing representations remain legal-gated.

### V7 — Arena

Subscriptions, passes, competition services, or other economics **only** for adapters whose IP status permits the relevant commercial use. No monetizing an adapter after permission disappears.

### V8 — Events / Media

Tournament/event services; sponsorship; consented media revenue sharing. Prize economics remain jurisdiction-gated.

### V9 — High-Value Infrastructure

Lawful referral/origination/service economics with insurers, graders, authenticators, custody providers, and licensed financial partners. Teloa does **not** become the regulated principal merely because it supplies the technology. No unlicensed lending revenue.

### V10 — Universal Network

Category certification; partner/network infrastructure; category packs; enterprise capabilities; scaled network economics.

## 3. Hard non-monetization prohibitions `[FOUNDER]`

Preserve verbatim as manufacturing blockers:

1. No selling user attention through addictive feeds  
2. No selling private reservation thresholds or location data  
3. No dark-pattern auto-listing  
4. No monetizing an IP adapter after permission disappears  

Also forbidden: secret listing for revenue; degrading basic Quiet Matching to force paid upgrades; mixing sponsored into “best” rank.
