Avatar Widget Prototype

This is the LifeOS assistant persona as a draggable corner companion. It can shrink to a badge, expand to a face, show expressions, and signal which channels are active.

Try it: drag the badge, double-click to expand/collapse, or use the buttons to change its mood. The expression and border color are wired to a state object so the Tonality / Face engines can drive them later.
