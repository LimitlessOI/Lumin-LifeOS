# Founder Packet — Constitutional Learning Architecture

**Mission ID:** `FACTORY-CONSTITUTIONAL-LEARNING-ARCHITECTURE-0001`  
**Product:** BuilderOS  
**WHAT:** Implement the engines and data schemas defined in `docs/products/builderos/specs/CONSTITUTIONAL_LEARNING_ARCHITECTURE.md` so Taloa can continuously improve understanding through reality.

## Intent

Taloa is a constitutional learning institution. The first buildable slice was the Enforcement Matrix (Phase 0). Phase 1 installs the learning architecture: Reality Alignment, Confidence Vectors, Human Constellation, Causality, Readiness, Perspective Expansion, and the Solomon Wisdom Lab. Phase 2 installs safety and coaching. Phase 3 installs BuilderOS self-improvement.

## Non-Negotiables

- The Human Constellation is the canonical person model; all OS products project it.
- No office becomes the source of truth; every engine is calibrated by reality.
- Every engine must include a `Mission Contribution` field.
- Builder Simplicity: prefer the simplest implementation that preserves future adaptability.
- All new `.js` files must include an `@ssot` JSDoc tag pointing to `docs/products/builderos/PRODUCT_HOME.md`.
